# Manual: importar datos actuales sin ponerlos en peligro

1. Abre Voltflow desde la misma URL y el mismo perfil de Chrome habitual.
2. En `Gestion de Datos`, pulsa `Crear copia completa ahora`.
3. Elige una contrasena maestra de al menos 12 caracteres y guardala fuera de Voltflow.
4. Pulsa `Comprobar copia` y selecciona el archivo descargado.
5. Pulsa `Recuperar datos antiguos` y selecciona una copia anterior.
6. Revisa el formato, cantidades, conflictos y avisos. Los valores de claves nunca se muestran.
7. Si una clave antigua difiere, decide expresamente si conservar la actual o usar la importada. Elegir una clave no autoriza ningun proveedor.
8. Dentro del asistente, crea otra copia del estado actual y seleccionala desde disco para demostrar que coincide exactamente con el navegador.
9. Pulsa `Fusionar datos`. No cierres la pestana durante la operacion.
10. Revisa el informe y comprueba empresas, contactos, comunicaciones y oposiciones.
11. Crea y verifica una nueva copia cifrada del estado ya fusionado.

No uses el perfil real para probar archivos de origen dudoso. Primero utiliza un perfil temporal y una copia del archivo. Nunca subas un backup a GitHub, JSONBin o un servicio de terceros.
